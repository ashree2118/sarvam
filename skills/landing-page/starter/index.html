Your questions, answered

What is Saaras V4?
Saaras V4 is Sarvam's latest speech-to-text model. It auto-detects the spoken language and transcribes across all 22 supported Indian languages plus Indian English, with five output modes (transcribe, translate, verbatim, translit, codemix) and key term prompting for names, brands and domain-specific terms. It handles code-mixed audio and is optimised for both real-time and batch processing.
What API types are available?
Three variants: a REST API for files under 30 seconds with synchronous processing, a Batch API for files up to 2 hours with speaker diarisation and timestamps, and a Streaming API for real-time transcription over WebSocket. The Realtime Streaming API (beta) also returns interim transcripts while the user is still speaking.
What audio formats are supported?
10+ formats, including MP3, WAV, AAC, OGG, Opus, FLAC, M4A, AMR, WMA and WebM. The Streaming API supports WAV and raw PCM at a 16 kHz sample rate.
Does it support speaker diarisation?
Yes. The Batch API identifies up to 20 speakers per audio file and labels each segment with timestamps. It's ideal for meetings, interviews and call-centre analytics.
