For developers

Add Text to Speech to your app in minutes

One model string, one language code. The same API you already use for Bulbul V3.

  • API
  • Playground
  • Content Studio
  • 8 kHz to 48 kHz
Python tts.py 
from sarvamai import SarvamAI

client = SarvamAI(api_subscription_key="YOUR_API_KEY")

audio = client.text_to_speech.convert(
    text="नमस्ते, कैसे हैं आप?",
    target_language_code="hi-IN",
    model="bulbul:v4-flash",
)
